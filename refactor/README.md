# Woldia Luxury Debut

Design a visually stunning, premium, modern website homepage for

“LUXURY CAFE & RESTAURANT” located in Woldia, Ethiopia.

IMPORTANT:

This must NOT look like a generic cafe website template.

The visual identity should feel inspired by a high-end contemporary

restaurant interior: white luxury marble with subtle gold veins,

vertical natural walnut wood panels, warm ambient lighting, deep

botanical green plant walls, charcoal details, elegant glass, and

premium minimal architecture.

DESIGN DIRECTION:

Create an immersive luxury hospitality experience that immediately

makes visitors feel they are entering the actual restaurant.

COLOR PALETTE:

- Luxury marble / main background: #F4F1E8

- Warm ivory: #E9E2D3

- Natural walnut wood: #8A5A3C

- Dark walnut: #4A2D20

- Premium charcoal: #151A1B

- Soft luxury gold: #C9A45C

- Deep botanical green: #183D2B

- Warm highlight: #FFF8E8

TYPOGRAPHY:

Use a sophisticated combination of:

- Elegant high-contrast serif font for major headings

- Clean modern sans-serif for navigation, buttons, descriptions and UI

Typography should feel expensive, spacious and editorial.

HERO SECTION — HIGHEST PRIORITY:

Create a full-screen immersive animated hero.

Use a cinematic image or video-style visual of the cafe interior as

the hero background. The image should slowly zoom inward using a very

subtle Ken Burns effect.

Add layered animation:

1. Background slowly scales from 1.0 to 1.08

2. A soft warm light moves subtly across the marble/wood environment

3. Small elegant particles or floating light dust move very subtly

4. Hero content enters in sequence:

   - small eyebrow text fades upward

   - large headline reveals word by word or with a smooth mask animation

   - description fades in

   - buttons appear last with a subtle upward motion

5. Add a premium animated vertical gold line or decorative element

6. Use a very subtle dark-to-transparent overlay so text remains readable

7. Include a gentle scroll indicator animation at the bottom

Hero copy:

EYEBROW:

WELCOME TO WOLDIA

MAIN HEADLINE:

Where Every Moment

Feels Like Luxury.

Alternative headline emphasis:

Luxury in Every Sip.

Flavor in Every Moment.

DESCRIPTION:

Experience exceptional coffee, delicious cuisine, handcrafted desserts,

and unforgettable moments in an elegant atmosphere at the heart of Woldia.

PRIMARY CTA:

Explore Our Menu

SECONDARY CTA:

Reserve a Table

Make the buttons premium:

- Primary: charcoal background with warm ivory text

- Hover: soft gold accent with smooth transition

- Secondary: transparent with elegant border

- No excessive rounded “startup SaaS” buttons

NAVBAR:

Create a transparent navbar over the hero that transforms on scroll

into a solid warm ivory / marble-colored navbar with subtle blur.

Logo:

LUXURY

CAFE & RESTAURANT

Navigation:

Home

Our Story

Menu

Gallery

Reservations

Cake Selection

Contact

Include an elegant “Reserve a Table” button.

AFTER HERO:

Create a smooth transition from the cinematic dark hero into a bright

luxury marble section.

SECTION: THE LUXURY EXPERIENCE

Use an asymmetric editorial layout.

Large serif heading on one side and cafe imagery on the other.

Include subtle vertical walnut wood details as visual separators.

SECTION: OUR MENU

Do not use a boring grid of identical cards.

Create a premium menu preview with categories:

Coffee

Breakfast

Main Dishes

Desserts

Fresh Juices

Use elegant food photography with hover animations.

On hover:

- image subtly zooms

- gold accent line expands

- item details smoothly reveal

SECTION: SIGNATURE EXPERIENCE

Create three premium experience cards:

☕ Exceptional Coffee

🍽 Refined Dining

🎂 Custom Cakes

Use subtle glass, shadows and architectural spacing.

Cards should feel like luxury hospitality, not a tech dashboard.

SECTION: CAKE SELECTOR

Highlight custom cakes for:

Birthday

Wedding

Graduation

Special Celebrations

Use large visual image cards.

Make this section highly interactive and visually attractive.

Users should be able to quickly choose an occasion and begin ordering.

SECTION: INTERIOR / GALLERY

Take inspiration from the actual cafe:

- vertical walnut wall panels

- white marble with gold veins

- warm ceiling lights

- botanical green walls

- modern seating

- elegant coffee and dessert displays

Create a masonry or asymmetric editorial gallery.

Images should animate smoothly into view on scroll.

Clicking an image should open an elegant fullscreen lightbox.

SECTION: RESERVATION

Use a dramatic split layout:

one side with a luxurious restaurant atmosphere image,

the other side a minimal reservation form.

Fields:

Name

Phone Number

Number of Guests

Date

Time

Special Request

Add:

“Reserve your table and let us prepare your experience.”

SECTION: LOCATION

Present Woldia, Ethiopia prominently.

Include:

Opening Hours

Phone

Location

Google Maps CTA

FINAL CTA:

Use a visually dramatic dark charcoal section with warm gold details.

Headline:

Your Table Is Waiting.

CTA:

Reserve Your Experience

FOOTER:

Dark charcoal background #151A1B

Warm ivory text

Subtle gold lines

Walnut-inspired decorative details

ANIMATION SYSTEM:

The website must feel alive but NEVER over-animated.

Use smooth, premium, cinematic motion:

- slow image zoom

- fade and upward reveals

- staggered text animations

- scroll-triggered section reveals

- subtle parallax

- elegant hover transitions

- image scale on hover

- gold line expansion

- smooth page transitions

Avoid:

- bouncing animations

- flashy gradients

- excessive glassmorphism

- neon colors

- generic coffee cup illustrations everywhere

- oversized rounded cards

- cheap-looking animations

- cluttered layouts

RESPONSIVE DESIGN:

Mobile must be treated as a premium first-class experience.

The hero should remain visually dramatic on mobile.

Navigation should transform into an elegant menu.

Text, images and CTAs must remain easy to access.

OVERALL MOOD:

Awwwards-level modern hospitality website.

Cinematic.

Architectural.

Warm.

Sophisticated.

Minimal.

Luxurious.

Confident.

The final result should make someone in Woldia think:

“This is not just a cafe website. This feels like entering a premium

restaurant before I even visit it.”

## Tech stack

Vite, React, TypeScript, and Tailwind CSS.

## Development

You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```

Other available scripts:

```sh
npm run build     # production build (outputs to dist/)
npm run preview   # preview the production build locally
npm run lint      # lint the project
npm run format    # format the project with prettier
```
